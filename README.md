# My Day

> **Plan Your Day. Complete Your Goals.**

A modern, fast, and distraction-free personal productivity and planning web application built with React 19, TypeScript, Vite, and Tailwind CSS.

Zero-backend architecture: all data is safely stored on your device via `localStorage`.

---

## ✨ Features

- 🏠 **Today View**: Focused daily agenda with real-time completion progress tracking.
- 📅 **Weekly View**: Monday → Sunday layout with day pills and daily task breakdowns.
- 🗓 **Monthly View**: Visual calendar grid with pending/completed indicators.
- 🎯 **Yearly Goals**: Milestones with actionable sub-checklists and progress bars.
- 🔮 **Future Plans**: Someday ideas with a 1-click **"Move to Today"** button.
- ✅ **Completed Archive**: History of finished tasks with restore and clear-all options.
- 📅 **Add to Calendar**: Exports RFC 5545 compliant `.ics` calendar files with reminders for Apple Calendar, Google Calendar, Outlook, and mobile calendar apps.
- 🔄 **Recurring Tasks**: Simple Daily, Weekly, Monthly, and Yearly task recurrence.
- 🌓 **Themes**: Light Mode, Dark Mode, and System auto-detection.
- 🔒 **Privacy & Backup**: No backend, no telemetry. Full JSON Export & Import backup support.
- 📱 **PWA Ready**: Offline support, Service Worker, and installable on Android, iOS, and Desktop.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+)
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/godmaster419/myday.git

# Navigate to project directory
cd myday

# Install dependencies
npm install

# Start local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Building for Production

```bash
npm run build
```
